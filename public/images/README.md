# トップページのカード画像

ここに下記の名前で画像を置くと、トップページのアイコンがその画像に差し替わります。
（下の表は「登録するメリット」の4枚。まだ未配置です）
置いていないものは、これまでのアイコンがそのまま表示されます。1枚ずつ差し替えられます。

| ファイル名 | 使われる場所 |
| --- | --- |
| `benefit-owners.png` | 登録するメリット：スペースオーナーの目に留まる |
| `benefit-appeal.png` | 登録するメリット：あなたの魅力を最大限にアピール |
| `benefit-free.png` | 登録するメリット：完全無料で利用可能 |
| `benefit-chances.png` | 登録するメリット：出店チャンスが広がる |

配置済み（差し替えるときは同じ名前で上書き）:

| ファイル名 | 使われる場所 | 形 |
| --- | --- | --- |
| `role-vendor.jpg` | できること：出店したい方 | 横長の写真（16:7・1200×525） |
| `role-organizer.jpg` | できること：イベントを開きたい方 | 横長の写真（16:7・1200×525） |

この2枚はカード上部の帯として出しています。小さなアイコン枠ではないので、
差し替えるときも横長の写真を用意してください。

## 画像の条件（アイコン枠の4枚）

- **正方形**（縦横が同じ比率）
- **512px 以上**を推奨（表示は48px前後だが、高解像度の画面で粗くならないように）
- **背景は透過**（PNG または SVG）。カード側の薄いオレンジの背景の上に載ります
- 余白は画像側に入れなくてよい。表示するときにこちらで少し余白を取ります

拡張子を PNG 以外にしたい場合は `src/lib/homeImages.ts` を変更してください。
